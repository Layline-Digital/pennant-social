# Troubleshooting & FAQ

### Where are keys stored?
All credentials live in local memory on 127.0.0.1:7420. Private keys are never exported.

### How do Core Hashtags work?
Clicking the star icon on any hashtag in your stash marks it as a Core Default, auto-checking it whenever you compose.

### How do I back up my setup?
Click Config -> Export Backup (JSON) to save your layouts and tags to a single file.
