# Quickstart Guide

You can run Pennant Hoist as a compiled desktop app or directly from source.

## Option 1: Desktop App (Windows)
Download the installer from Releases:
- Pennant Hoist-setup.exe (NSIS installer, ~1.1 MB)
- Pennant Hoist.msi (MSI package, ~1.6 MB)

## Option 2: Run from Source (Node 20+)
git clone https://github.com/Layline-Digital/pennant-social.git
cd pennant-social
npm install
npm test
npm run dev

Open http://127.0.0.1:7420 in your browser.

## First Broadcast
1. Click + ADD COLUMN to mount your feeds.
2. Click + NEW BROADCAST to open the composer.
3. Arm your target switches (ATProto, Mastodon, Nostr).
4. Type your message and click TRANSMIT RECORD.
